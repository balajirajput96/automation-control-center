# NIFTY Market Data Entity Card

| Field | Value |
|---|---|
| Common name | NIFTY 50 Index |
| Market-data symbol | `^NSEI` |
| Exchange / market | National Stock Exchange of India / India equity index |
| Instrument type | Broad-market equity index, not an operating company |
| Currency | INR |
| Reference-date policy | Each UI response shows its own retrieval timestamp and source-delayed status. |
| Initial structured source | Yahoo Finance chart endpoint through the server-side Data API helper, region `IN`, language `en-IN`. |

The module is an informational monitoring surface only. It must not provide personalized investment recommendations, execution, or trading signals.
